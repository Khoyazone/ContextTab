Privacy

Data sent for each tab: title (150 characters max.), domain, URL path without parameters (long identifiers masked), and any search query. Never page content.

Never sent: pinned tabs, incognito browsing, chrome:// / about: pages, or excluded domains.

Google account: only the openid permission is requested (no name or e-mail). The server keeps a pseudonymous identifier and daily counter, deleted after 2 to 3 days.
